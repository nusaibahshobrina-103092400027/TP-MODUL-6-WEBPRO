A. Jawaban Teori

1. Pengertian dan Kegunaan JavaScript

JavaScript adalah bahasa pemrograman yang digunakan untuk membuat website menjadi interaktif, seperti menampilkan pesan, menerima input pengguna, dan mengubah tampilan halaman.

2. Pengertian dan Kegunaan jQuery

jQuery adalah library JavaScript yang mempermudah pengaturan elemen HTML, penanganan klik tombol, dan perubahan tampilan website.

3. Perbedaan JavaScript dan jQuery

JavaScript adalah bahasa pemrograman, sedangkan jQuery adalah library berbasis JavaScript yang mempermudah penulisan kode untuk memanipulasi elemen HTML dan menangani interaksi pengguna.
