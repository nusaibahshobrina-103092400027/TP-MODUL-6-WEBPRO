 1. Pengertian dan Kegunaan JavaScript

JavaScript adalah bahasa pemrograman yang digunakan untuk membuat website menjadi interaktif. JavaScript dapat digunakan untuk menampilkan pesan, menerima input pengguna, memvalidasi form, dan mengubah tampilan halaman website.

 2. Pengertian dan Kegunaan jQuery

jQuery adalah library JavaScript yang mempermudah penulisan kode untuk mengatur elemen HTML, menangani klik tombol, mengubah tampilan, serta menyembunyikan dan menampilkan elemen website.

 3. Perbedaan JavaScript dan jQuery

JavaScript adalah bahasa pemrograman yang dapat digunakan untuk membuat website interaktif tanpa library tambahan. Sementara itu, jQuery adalah library berbasis JavaScript yang menyediakan sintaks lebih ringkas untuk memanipulasi elemen HTML dan menangani interaksi pengguna.

Contohnya, JavaScript dapat memilih elemen menggunakan `document.getElementById()`, sedangkan jQuery dapat menggunakan `$("#id")` untuk memilih elemen berdasarkan ID.
